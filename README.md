# Quiz Bot

Telegram-бот с квизами и опросами на aiogram 3. Всё содержимое — тексты, картинки, вопросы, сами квизы — настраивается из админ-панели прямо в Telegram, без правки кода.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # и впиши токен и свой ID
python bot.py
```

В `.env` две строки:

- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
- `ADMIN_IDS` — Telegram ID владельцев через запятую. Свой ID можно узнать, запустив бота и отправив ему `/id`

База — SQLite в `data/quiz.db`, создаётся сама. При первом запуске добавляется стартовый квиз «📝 Квиз» на 15 вопросов — его можно править или удалить из панели.

## Что умеет

**Для пользователей**
- меню со всеми опубликованными квизами, приветствие с картинкой
- вопросы с вариантами (кнопки) и с ответом текстом
- проверка текстовых ответов не зависит от регистра, «ё» и знаков препинания, можно задать несколько верных формулировок
- после ответа — разбор и пояснение, в конце — результат, оценка и личный рекорд
- вопросы без правильного ответа — для опросов, они не влияют на счёт
- выход посреди квиза сохраняет прогресс, можно продолжить
- по умолчанию каждый квиз можно пройти один раз — пройденные отмечены ✅ в меню
- прямые ссылки на квиз: `t.me/<бот>?start=q<id>`

**Админ-панель** (`/admin` или кнопка в меню)
- создание, редактирование, публикация, скрытие и удаление квизов
- переключатель «🔒 Одна попытка / 🔁 Без ограничений» и кнопка «♻️ Сбросить прохождения» — после сброса все снова могут пройти квиз, статистика сохраняется. Админы могут перепроходить квизы всегда, чтобы проверить
- название, описание, обложка
- пошаговый мастер вопросов: текст → тип → ответы → картинка → пояснение
- изменение любой части вопроса, перестановка, удаление
- статистика по каждому вопросу и выгрузка всех ответов в CSV
- текст и картинка приветствия, `{name}` подставляет имя пользователя
- выдача и отзыв доступа по Telegram ID, пересланному сообщению или из контактов

**Защита от случайностей**
- двойные и тройные нажатия засчитываются один раз
- старые кнопки не ломают прохождение
- если админ удалил вопрос или квиз, пока его проходят, бот аккуратно это обработает
- картинка, присланная файлом, принимается так же, как фото
- лимиты длины с понятными подсказками
- `/cancel` или «✖️ Отмена» в любом шаге панели

## Структура

```
bot.py              запуск
config.py           чтение .env
database.py         SQLite: квизы, вопросы, попытки, ответы
ui.py               отрисовка «одного окна», картинки, мелочи форматирования
demo.py             стартовый квиз
commands.py         меню команд Telegram
middlewares.py      учёт пользователей и проверка прав
handlers/
  common.py         /start, /id, /help, /cancel
  user.py           меню и прохождение квизов
  fallback.py       устаревшие кнопки и прочее
  admin/
    views.py        экраны панели
    forms.py        приём ввода
    panel.py        главная панели, оформление, админы, статистика, CSV
    quizzes.py      квизы
    questions.py    вопросы
assets/             картинки приветствия, обложки и вопросов
```

Состояния мастеров панели хранятся в памяти: если перезапустить бота посреди создания вопроса, этот шаг придётся начать заново. Прогресс пользователей в квизах лежит в базе и перезапуск переживает.
